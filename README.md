# Exotic Notifier

This is the scanner the Discord loader downloads. Setup happens in the server.

1. Run `/adduser`.
2. Create an application at https://discord.com/developers/applications
3. Open **Bot**, click **Reset Token**, and copy the token.
4. Click **Paste token**. A DM sends a small zip and an invite link.
5. Open the invite link and add your bot to the server.
6. Unzip the download. Windows: double-click `start.bat`. Mac: double-click `Start ExoticNotifier.command`.
7. Leave that window open. It downloads this scanner, then opens one small Chrome window. Do not close that window, and do not start the loader twice.
8. In **#mange-your-noti**, click **Open my notifier**, then run `/start` on your bot.

Your bot token and the player list stay in the zip from the DM. They are not in this repo.
